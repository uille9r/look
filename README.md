# 字幕素材清单 · 教学练习

这是本教程原创的本地练习，不是一个已经公开的 GitHub 仓库。

它把目录中的字幕文件整理成 CSV 清单。**只统计匹配 SRT 时间轴格式的行数**；不统计字数、不转写音频、不判断内容、不调用 AI，也不剪视频。样例文字为教学原创。

## 环境与第一次运行

需要 Python 3.10 或更新版本，全部使用标准库，不需要安装第三方包。在终端进入解压后的 `subtitle-lab` 目录，再运行：

```bash
python3 --version
python3 summarize.py samples report.csv
```

Windows 的命令名如果是 `py`，使用 `py --version` 和 `py summarize.py samples report.csv`。生成的 `report.csv` 是带 UTF-8 BOM 的 CSV，可用表格软件打开。重复运行会覆盖这个输出文件。

预期结果按文件名排序，两份文件共 4 段：

```csv
file,cues
片头.srt,1
访谈.srt,3
```

“已统计 2 个字幕文件”是文件数；CSV 两行 cues 的和是字幕段数。两者不要混淆。

## 检查结果

```bash
python3 -m unittest -v
```

初始版本有 3 个测试：样例结果与中文/BOM、空目录仍有表头、无效路径报中文错误并返回非零。补上大写字幕后缀后共 4 个。实际 GitHub Actions 尚未运行；`.github/workflows/check.yml` 展示以后上传到自己的练习仓库时可以使用的配置。

## 你要做的小功能

初始版本只识别小写 `.srt`，会跳过 `片尾.SRT`。请让它同时识别大写后缀，先补一个能复现问题的测试，再做最小修复。

验收：临时目录放入含 1 条时间轴的 `片尾.SRT`，CSV 应出现 `片尾.SRT,1`；原有 3 项检查仍通过；`.txt` 不应进入结果。详见 `练习任务.md`。

## 当前边界

- 只扫描指定目录的第一层，不递归子目录。
- 接受 `.srt` 后缀且不区分大小写（`.srt`、`.SRT`、`.Srt` 均可），CSV 中的文件名保留原始大小写。
- 输入文件使用 UTF-8（可带 BOM），时间轴格式为 `00:00:00,000 --> 00:00:02,000`。
- 按时间轴行计数，不做完整 SRT 合法性校验；时间格式匹配不代表时间逻辑正确。
- 空目录输出表头；输入目录不存在或是文件时，显示中文错误并非零退出。
- 输出文件的父目录须已存在且可写；不要把大视频、密码、cookie 或 `.env` 加入练习仓库。
